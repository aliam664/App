# mods/ — bundled content

Everything in this folder is packaged next to the app and installed onto the
player's Assetto Corsa folder. **Full guide: [../ADMIN-GUIDE.md](../ADMIN-GUIDE.md)**

```text
graphics/<low|medium|high|veryhigh|ultra>/   mirror of the game folder, one per tier
graphics/common/                             optional, copied before the tier
addons/<id>/{mod.json, preview.png, files/}  optional add-ons; files/ mirrors the game folder
```

# UHM Pack Installer

## چطور اجرا کنم؟ (روی ویندوز خودت)

۱. Node.js رو نصب کن (نسخه ۱۸ به بالا) از nodejs.org

۲. توی پوشه‌ی پروژه، ترمینال (PowerShell یا CMD) باز کن و بزن:
```
npm install
```
این دستور کتابخانه‌های لازم (electron و...) رو دانلود و نصب می‌کنه. (به اینترنت نیاز داره، فقط همین یه بار)

۳. برای اجرای برنامه در حالت توسعه:
```
npm start
```

۴. برای ساختن فایل نصبی نهایی (exe):
```
npm run dist
```
خروجی توی پوشه‌ی `dist/` قرار می‌گیره.

## وضعیت فعلی پروژه (چی آماده‌ست؟)

✅ اسکلت برنامه (پنجره فریملس، گردگوشه، قابل تغییر اندازه)
✅ تم شب/روز (قابل تغییر از نوار بالا یا تنظیمات)
✅ زبان فارسی/انگلیسی (قابل تغییر، RTL/LTR خودکار)
✅ صفحه شوکیس با اسلایدشو ۹ عکس
✅ صفحه تنظیمات (زبان، تم، مسیر بازی)
✅ صفحه درباره ما (لینک‌های تلگرام/یوتیوب)
✅ زیرساخت مانیفست نصب (ذخیره/خواندن از دیسک)
✅ توابع آماده در main.js برای: انتخاب مسیر بازی، اعتبارسنجی، جستجوی خودکار استیم، چک CSP/PURE موجود، کپی با بکاپ، بازگردانی/حذف

## چیزهایی که هنوز ساخته نشدن (قدم بعدی)

- صفحه‌ی انتخاب مسیر بازی (UI)
- صفحه‌ی بررسی فایل‌های پایه (UI)
- صفحه‌ی انتخاب سطح سیستم (Low/Medium/High/VeryHigh/Ultra)
- صفحه‌ی نصب خودکار (اجرای واقعی کپی/اکسترکت ۷ مود)
- صفحه‌ی پایانی
- صفحه‌ی مدیریت/حذف مودها
- قرار دادن فایل‌های واقعی مودها (CSP, Video, PURE, PP Filter, Chase Cam, HUD, SRP Light) داخل پوشه‌ی assets/mod-files

## نکته‌ی مهم درباره‌ی آیکون exe

فایل `src/assets/images/icon.ico` که توی package.json بهش اشاره شده هنوز وجود نداره. باید یه نسخه‌ی .ico از لوگو بسازی و همونجا بذاری (یا بعداً با هم می‌سازیمش).

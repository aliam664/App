# UHM Launcher Platform — نسخه پایلوت متصل به سرویس واقعی

نصب‌کننده Windows x64، متصل به پروژه مستقل UHM Launcher در Supabase؛ با UI مشترک سایت، مجوز دستگاه، پنل مدیریتی لایسنس‌محور و موتور نصب Native.

**این فایل امضای دیجیتال Authenticode ندارد.** ممکن است Windows SmartScreen هشدار ناشر ناشناس بدهد. این نسخه برای شروع کنترل‌شده و آزمون عملی است، نه گواهی امنیت یا انتشار تجاری تضمین‌شده. فایل را فقط از همین release بگیرید و SHA-256 را با `SHA256SUMS.txt` مقایسه کنید. اگر هش متفاوت بود نصب نکنید.

- فایل `UHM-Launcher-0.1.0-x64-setup.exe` را دریافت کنید؛ ZIP و Source code نصب‌کننده نیستند.
- کد لایسنس جداگانه و خصوصی صادر می‌شود؛ هیچ کدی در این release وجود ندارد.
- اولین فعال‌سازی به کلید همان دستگاه متصل می‌شود. مالک باید کدش را نخست در برنامه Windows روی دستگاه نهایی وارد کند، نه برای امتحان در مرورگر.
- پروژه ابتدا کاتالوگ خالی دارد؛ فایل، لینک واقعی و SHA-256 بسته‌ها را از پنل ثبت و منتشر کنید.
- برنامه هنوز updater امضاشده خودکار ندارد؛ برای نسخه بعدی، نصب‌کننده جدید را از release مشخص دریافت کنید.
- این محصول جدید با release قدیمی `v1.0.0` مربوط به Electron متفاوت است. آن release تغییری نکرده است.

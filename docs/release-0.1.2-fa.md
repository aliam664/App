## محدودیت‌های باقی‌مانده

- امضای updater معتبر و مستقل از لایسنس است؛ **گواهی ناشر Authenticode ویندوز اضافه نشده** و SmartScreen ممکن است هشدار بدهد.
- بازی واقعی، نصب تعاملی روی رایانهٔ شخصی و قطع برق عمدی آزموده نشدند. آزمون فعال‌سازی روی لایسنس Owner عمداً انجام نشد؛ حفظ هویت دستگاه فقط در صورت موجودبودن فایل DPAPI در CI بررسی می‌شود.
- آزمون Native زنجیرهٔ پکیج، فایل/شبکه/هش/استخراج واقعی دارد؛ فقط event runtime و تأیید preview در آن callback آزمایشی‌اند، نه تأیید دستی کاربر.
- rollback فیزیکی فایل شخصیِ تغییرکرده مجوز نگرفته و اجرا نمی‌شود؛ restore سرور فقط پیش‌نویس جدید می‌سازد. بسته‌های موجود تولید برای آزمایش منتشر/ویرایش نشدند.
- این انتشار به معنی بسته‌شدن همهٔ یافته‌های ممیزی امنیت تاریخی یا تضمین «ضدکرک کامل» نیست؛ پشتیبانی آفلاین و محدودیت منابع سرویس رایگان برقرارند.
- انتشار سراسری فید تأیید شد؛ **نصب موفق روی همهٔ رایانه‌ها ادعا نمی‌شود**.

# UHM Launcher 0.1.1 — رابط جدید و اصلاحات نهایی

این نسخه آخرین بازطراحی Owner و اصلاحات رابط کاربران را به **نصاب ویندوز** می‌رساند؛ صرفاً به‌روزرسانی سایت نیست. انتشار در همان کانال prerelease و feed امضاشده انجام می‌شود و legacy latest را جایگزین نمی‌کند.

## تغییرات

- پنل Owner جدید، میان‌برهای واقعی، آمار مبتنی بر permission و تم روشن/تاریک اصلاح‌شده.
- اصلاح فرم پکیج در موبایل، منوی تبلت/موبایل، لینک لوگو، کنتراست، فیلترها و دسترس‌پذیری.
- حفظ صفحه در refresh/history، تلاش دوباره پس از خطای موقت، هشدار فرم ذخیره‌نشده و مدیریت بهتر focus/اعلان‌ها.
- اصلاح AUD-02 و AUD-03 در رابط بدون اعطای ضمنی مجوز بیشتر یا تغییر API تولید.
- هم‌ترازی نسخهٔ npm، Cargo، نصاب، رابط و telemetry؛ آزمون خودکار جلوگیری از ناسازگاری نسخه اضافه شد.

کلید امضای لایسنس و updater، identifier برنامه و محل تنظیمات/دستگاه همان قبلی‌اند؛ reset لایسنس یا ساخت کلید جدید لازم نیست.

## محدودیت‌ها

- نسخه **آزمایشی** است؛ چهار یافتهٔ بازِ سمت سرور در ممیزی قبلی با این تغییر رابط رفع نشده‌اند.
- امضای updater برای کنترل bytes و نسخه است، نه Authenticode/گواهی ناشر Windows؛ هشدار SmartScreen همچنان ممکن است.
- قبولی build، آزمون رابط یا updater به معنی تأیید همه مودها/هاست‌ها، بازی واقعی یا همه GUIهای کاربر نیست.
- نسخهٔ قدیمی فاقد updater به نصب یک‌باره نیاز دارد. کاربران نسخهٔ updaterدار، این نسخه را طبق سیاست موجود در پس‌زمینه و هنگام خروج امن/اجرای بعدی دریافت می‌کنند؛ بازی و کار فعال نباید قطع شوند.
